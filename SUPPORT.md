# Suporte

## Como pedir ajuda

Use uma issue para problemas reproduzíveis no site, documentação ou sugestões de melhoria. Inclua a página, navegador, dispositivo, comportamento observado e resultado esperado.

Antes de abrir a issue:

- leia o [README](README.md) e o [guia técnico](docs/REPOSITORY_GUIDE.md);
- confirme se o problema já não foi relatado;
- não inclua credenciais, dados pessoais ou links internos.

Para uso da marca e assets oficiais, consulte [CKF Design](https://github.com/Kauerc10/ckf-design). Para segurança, siga [SECURITY.md](SECURITY.md).
